# GRU_mARN_Analysis

Dự đoán **độ phân huỷ của vaccine mRNA Covid-19** từ dữ liệu chuỗi, dùng mô hình
**GRU** xây bằng Keras/TensorFlow.

## Nội dung

- `Covid_19_mRNA_Vaccine_Degradation_Prediction.ipynb` — EDA, tiền xử lý, huấn
  luyện GRU, đánh giá.
- `train.json`, `test.json`, `data.json` — dữ liệu chuỗi đầu vào.
- `model.keras` — mô hình đã huấn luyện.
- `LICENSE`.

## Chạy

```bash
jupyter notebook Covid_19_mRNA_Vaccine_Degradation_Prediction.ipynb
```
